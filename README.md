# Swiggy SQL Analytics Project

This repository contains SQL-based analysis performed on a Swiggy restaurant dataset.  
The objective is to derive insights related to restaurant performance, revenue generation, city-level trends, and cuisine pricing using MySQL.

## Project Overview
The project focuses on:
- Revenue analysis
- City-wise restaurant distribution
- Cuisine-level pricing trends
- Rating-based filtering
- Ranking restaurants using window functions
- Percentile-based insights (top 1% and top 20%)

## Dataset
Table: restaurants  
Columns: name, city, cuisine, cost, rating, rating_count

## Example Queries

### Top 5 restaurants of every city
SELECT name, city, (rating_count * cost) AS revenue 
FROM (
    SELECT name, city, rating_count, cost,
           ROW_NUMBER() OVER(PARTITION BY city ORDER BY rating_count * cost DESC) AS ranks
    FROM restaurants
) t
WHERE t.ranks < 6
ORDER BY revenue DESC;

Revenue generated by top 1% restaurants
SELECT SUM(rating_count * cost)
FROM (
    SELECT rating_count, cost,
           ROW_NUMBER() OVER(ORDER BY rating_count * cost DESC) AS rank
    FROM restaurants
) t
WHERE t.rank <= (SELECT CEIL(COUNT(*) * 0.01) FROM restaurants);
